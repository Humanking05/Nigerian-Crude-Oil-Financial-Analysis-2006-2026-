# Nigerian-Crude-Oil-Financial-Analysis-2006-2026
The "Why" (The Rationale)
This project analyzes Nigeria's primary economic engine to identify how price volatility and production trends affect national fiscal stability.

The "How" (Thought Process)
Data Lifecycle: Cleaned 20 years of data (2006–2026) to model revenue and efficiency.

Stress Testing: Modeled a "Shock Scenario" to show that a simultaneous drop in price and volume results in a 22.82% fiscal loss.

Findings: Identified a 42.52% structural decline in production since 2010.

The "Tech" (Local AI & Python)
Local LLM: Integrated Ollama with the Qwen 2.5 model.

Privacy & Speed: By running the model locally, I generated senior-level economic insights without using external APIs or compromising data privacy.

Automation: Used Python to auto-generate a professional, formatted PDF report (Nigeria_Oil_Analysis_Fixed.pdf) for stakeholders.
